## 💡 宣传话术核心要点（所有平台统一）

1. **主 slogan**：按住说话，松开即得，AI 自动润色
2. **核心差异**：不只是语音转文字，还能自动润色去口水词
3. **信任背书**：免费版可用、10 天 Pro 免费试用、不自动扣费
4. **价格锚点**：月付 ¥9（一杯奶茶钱）、年付 ¥89（每天 0.24 元）
5. **行动引导**：官网 voxtype.net / 评论区置顶链接

## 🚨 注意事项

1. **抖音**：背景音乐需用平台版权音乐库，避免侵权
2. **小红书**：图片建议加品牌水印，防止被盗图
3. **B站**：视频标题控制在 20 字内，封面文字要清晰可读
4. **公众号**：推文发布前需预览，注意排版在手机上的效果
5. **统一话术**：各平台对产品的描述需保持一致，避免用户混淆
